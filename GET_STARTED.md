## 🚀 Quick Start (5 Minutes)

### Step 1: Prerequisites Check ✅
Make sure you have:
- ✅ XAMPP installed
- ✅ Node.js installed (v18+)
- ✅ Firebase account created

### Step 2: Database Setup 🗄️
1. Open XAMPP Control Panel
2. Start **Apache** and **MySQL**
3. Open http://localhost/phpmyadmin
4. Click **Import** → Select `database/schema.sql` → Click **Go**
5. ✅ Database `leveluplife` created!

### Step 3: Firebase Configuration 🔥
1. Go to https://console.firebase.google.com/
2. Create a new project (or use existing)
3. Enable **Authentication** → **Email/Password** and **Google**
4. Get your config from **Project Settings** → **General** → **Your apps**
5. Copy `.env.example` to `.env`
6. Paste your Firebase credentials in `.env`

### Step 4: Install & Run 🎯
```bash
# Install dependencies
npm install

# Start the app
npm run dev
```

### Step 5: Open & Enjoy! 🎉
- Open http://localhost:3000
- Sign up with email or Google
- Start your journey!

## 🆘 Troubleshooting

### Can't Login?
- Check Firebase credentials in `.env`
- Ensure Email/Password is enabled in Firebase Console
- Clear browser cache and try again

### Tasks Not Saving?
- Ensure XAMPP MySQL is running
- Check database connection in `api/config/database.php`
- Verify database `leveluplife` exists

### API Errors?
- Ensure XAMPP Apache is running
- Test: http://localhost/LevelUpLife/api/quotes/random.php
- Check browser console for errors

### XP Not Updating?
- Check daily XP limit (100 XP/day)
- Verify task completion was successful
- Refresh the page
