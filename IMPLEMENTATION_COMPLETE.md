## 🚀 How to Run

### **Step 1: Database Setup**
```bash
# Open phpMyAdmin or MySQL command line
mysql -u root -p leveluplife < database/setup_gamification.sql
```

### **Step 2: Start Dev Server**
```bash
npm run dev
```

### **Step 3: Open Browser**
```
http://localhost:5173
```
